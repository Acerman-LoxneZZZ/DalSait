# ДАЛЬ

Готовый авторский сайт о путешествиях: вращающаяся галерея направлений, анимации при прокрутке, маршрут с заполняющейся линией, полароидный фотоальбом и кинематографичная история в четырёх кадрах.

## Запуск

В этой папке выполните `node preview-server.mjs`, затем откройте http://127.0.0.1:4173.

Сайт не требует установки зависимостей или сборки. Готовые файлы находятся в `dist/`. Фотографии и шрифты сохранены локально. `index.html` можно также открыть напрямую; для работы в браузере предпочтителен локальный сервер.

## Управление

- Первый экран при прокрутке плавно проводит через четыре фотографии из фотоистории: озеро, горы, водопад и звёздное небо. Обратная прокрутка возвращает предыдущие кадры.
- Дальнейшая прокрутка поворачивает галерею и постепенно рисует линию маршрута.
- Стрелки переключают направления; фотография открывает историю места.
- Фотоальбом листается стрелками или горизонтальным жестом.
- «Почувствуй ДАЛЬ» открывает фотоисторию: следующий/предыдущий кадр, пауза и продолжение.
- Escape закрывает открытое окно; фокус возвращается к кнопке открытия.
- Настройка системы «Уменьшение движения» отключает автоматические анимации.

Это редакционный концепт, без бронирований и внешней отправки персональных данных. Источники фотографий указаны в файлах `dist/assets/*.origin.txt`. Шрифты: Manrope и Cormorant Garamond из Google Fonts. Взаимодействия созданы с нуля по мотивам предоставленных примеров 21st.dev.
